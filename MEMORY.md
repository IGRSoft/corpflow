## Version Tracking

- Plugin version: **4.0.29** — a wrong PR base is now blocking rather than invisible. The durable lesson is about what a check is entitled to conclude: `continuity` proved a branch had not diverged from *its recorded* base and was read for years as proving the base was right, which are different claims, and the gap between them let a 27-file run open a 1008-file PR with every check green. The new `base-sanity` compares the would-be PR diff against the run's own ledger — a magnitude cross-check between two independent records of the same run, which is the only thing that could have caught it. Second lesson, from the round-1 regression: **new evidence in a shared resolver defaults to opt-in**. Fork-point fill was first wired as rank 0 for every reader and broke callers that had a correct base already; scoped to the one check built to reconcile it (`--with-fork-point`), it is additive. Carried forward from 4.0.28 — the 26-fix code-review band plus the OV-183 closing-sweep fix: a sweep item's artifact stub and its ledger stub could disagree with nothing looking, because `_sweep_join` ORed `blocks_next_stage` (making `true` unclearable) and `check_sweep_ledger` compared ids only. The durable lesson is a distinction, not a patch — **the raise-only lattice is over LABELLERS, never TRANSPORTS**: `max(agent, orchestrator)` settles two parties labelling one item, while an agent's artifact stub and its own ledger stub are one author with two copies, so a disagreement there is a defect to refuse rather than a lattice to join. Joining them manufactured a boundary gate out of a bookkeeping slip. Carried forward from 4.0.27 — CC 2.1.234→2.1.251, themed on cross-agent and cross-session communication: the resume loop branches on a `SendMessage` delivery result instead of assuming it landed (why the min-CC floor moved), a stage needing a peer session's answer returns `blocked` with `cross_session_ask` for the orchestrator to send (a subagent's reply lands in the parent conversation, never on the stage), a `maxTurns` partial return routes to the existing reattach arm instead of a re-delegate, and a new `PreModelSwitch`/`PostModelSwitch` hook pair gates and records a mid-worktask re-tier away from a stage's pinned `metadata.model`
- Claude Code min required: **2.1.251** (README.md is authoritative; pinned to the band top, and this time load-bearing rather than conventional — the resume loop branches on the `SendMessage` non-delivery reporting that lands across 2.1.234–2.1.238)
